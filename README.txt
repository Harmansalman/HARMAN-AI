HARMAN AI - Front-end prototype

Contents:
- index.html: mobile-friendly, dark, Sorani-first prototype.

Deploy:
1. Extract this ZIP on your phone or computer.
2. In Netlify, choose Add new site / Deploy manually (or the upload project files area).
3. Upload the extracted folder or drag index.html into Netlify Drop.
4. This is a front-end prototype only. AI chat, voice, image generation, real authentication,
   payments, and live location sharing between people need secure backend services and APIs.
   The demo chat intentionally does not pretend to be a real AI model.
